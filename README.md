🌦️ TempoAgora

Aplicativo desenvolvido em .NET MAUI para consultar e exibir informações meteorológicas em tempo real, como temperatura, umidade, descrição do tempo e previsão atualizada.

📱 Funcionalidades

Consulta do clima atual por cidade.

Exibição de temperatura, sensação térmica e condições do tempo.

Interface simples e responsiva.

Tratamento de erros com HttpResponseMessage.StatusCode.

🛠️ Tecnologias Utilizadas

.NET MAUI

C#

API de previsão do tempo (ex: OpenWeatherMap
)

HttpClient para consumo da API

Programação assíncrona com async/await

📦 Instalação e Uso

Clone o repositório:

git clone https://github.com/seu-usuario/TempoAgora.git


Abra o projeto no Visual Studio.

Configure a chave da API de clima no código (appsettings.json ou diretamente no código, dependendo da implementação).

Execute o projeto no emulador ou dispositivo físico.
